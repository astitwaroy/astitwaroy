### About me

- 🛠️ I mainly write **C++**, and I'm happiest working on **backend systems** — APIs, services, anything where I'm reasoning about data flow and architecture rather than UI.
- 🤝 I like **collaborating on backend projects** — pulling apart a system, figuring out where it breaks, and making it better with someone else.
- 🧠 I'm spending a lot of time right now understanding **how AI systems are actually built** under the hood, not just how to call an API.
- 🧩 I solve problems for fun. **Competitive programming** is basically my hobby — see my Codeforces above.
- 📚 Also comfortable with **Kotlin, Python, JS, HTML/CSS** when a project calls for it.
